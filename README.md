## 项目范围

1. **大创：易购小车 / 购物随行小伴侣**：围绕 STM32、OpenMV、UWB、传感器和显示交互，规划商品识别、称重计价、自动跟随和避障链路；本人负责项目程序编写，并参与系统方案梳理。
2. **电子设计大赛：单目视觉目标物测量装置**：OpenMV 完成图像采集和目标特征提取，STM32 完成通信、标定计算、OLED 显示和控制；本人参与视觉处理、主控通信和显示联调。
3. **机器人及人工智能大赛：购物慧眼智慧无人称重计价系统**：把 CNN 商品识别、OpenMV 部署、STM32 串口接收、电子秤 ADC 数据、计价显示和语音播报连成完整方案；本人作为团队成员参与相关实现与方案整理。
4. **大创方案：BLE / 5G 中继智慧电网传感器**：围绕 TMR 电流与波形采集、低功耗 BLE、5G 中继和故障定位展示构建设计方案；页面中的指标明确标为方案材料指标。
5. **SOM 人工神经网络课程设计：用电异常用户监测**：使用 20×20 SOM、5 维用电特征、归一化、邻域衰减、重构误差和 95% 分位数阈值识别异常用户。
6. **学院中规模 PCB 培训**：组织和指导原理图阅读、元器件选型、布局布线、焊接装配、通电检查及万用表/示波器基础测量，强调从设计文件到实物验证的完整流程。
7. **机器人控制与传感器系统实践**：总结主控、传感器、执行器、串口和电源之间的系统集成与联调方法。
8. **计算机设计类竞赛 / 软件作品**：围绕智能监测、预警和数据展示类软件，参与需求梳理、功能实现、数据处理和作品材料整理。
