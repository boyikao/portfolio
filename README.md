## 项目索引

### 电子设计大赛：单目视觉目标物测量装置

基于 `OpenMV H7 Plus + STM32F103C8T6` 实现目标物距离和尺寸测量。

- 项目功能：图像采集、目标检测、特征提取、距离计算、尺寸测量、OLED 显示和功耗监测。
- 我的工作：参与电路方案设计、模块连接、OpenMV 与 STM32 通信联调、程序调试、测量验证和竞赛现场协作。
- 技术链路：OpenMV 负责图像处理，STM32 负责数据接收、二次计算、误差补偿和结果显示，双方通过 UART 通信。
- 公开证据：系统架构图、硬件原理图、STM32 流程图、圆形与三角形测试截图、报告测试表。
- 报告记录：距离误差控制在 5 cm 内，尺寸误差控制在 2 cm 内。

### 大创：易购小车 / 购物随行小伴侣

面向购物场景的自主移动小车原型，完成底盘、传感器、电源、控制程序和基础运动功能的集成验证。

- 项目功能：传感器数据采集、状态判断、电机驱动、基础运动控制和现场装配测试。
- 我的工作：参与系统方案拆解、硬件搭建、传感器接入、嵌入式程序开发、整机联调和故障排查。
- 公开证据：代码与识别流程截图、真实硬件照片、装配和测量记录。

### 机器人大赛：购物慧眼智慧无人称重计价系统

面向无人购物场景的称重、识别和计价系统，将商品识别、电子秤数据、计价逻辑和结果反馈连接成设备端流程。

- 项目功能：称重数据采集、商品识别、计价处理、显示反馈和语音播报方案。
- 我的工作：参与功能拆分、称重模块接入、串口数据流程、设备端调试、现场联调和材料整理。
- 公开证据：真实现场图、项目说明、原理图和软件著作权相关材料。

### 计算机设计类竞赛：低功耗蓝牙和 5G 中继的电网智慧化方案

围绕电网设备通信、低功耗采集、BLE 接入和 5G 中继构建智慧化方案。

- 项目功能：设备数据采集、低功耗蓝牙接入、5G 中继通信和上行展示。
- 我的工作：参与通信架构理解、资料整理、系统流程梳理、方案表达和竞赛展示材料制作。
- 公开证据：竞赛方案材料、系统流程说明和获奖证书。

### SOM 人工神经网络：用电异常用户监测

使用自组织映射神经网络对电力用户样本进行聚类观察和异常监测。

- 项目功能：CSV / Excel 样本整理、特征归一化、SOM 映射、聚类分析、异常识别和结果可视化。
- 我的工作：负责数据整理、SOM 方法学习、异常用户分析、图表制作和报告编写。
- 公开证据：样本字段可视化、SOM 聚类图、分析报告和结果记录。

### 学院中规模 PCB 培训

围绕一个可完成、可检查、可调试的硬件练习，组织从原理图到 PCB 实物验证的实践流程。

- 培训内容：原理图阅读与绘制、元件选型、PCB Layout、DRC 规则检查、焊接、通断测试和基础仪器测量。
- 我的工作：参与培训内容组织、设计流程讲解、焊接实践指导和硬件故障排查。
- 公开证据：PCB 布线图、DRC 检查图、设计流程图、完成板照片和培训实践记录。

## 我的工程工作链路

1. **理解题目**：提取功能约束、输入输出和评分或验证指标。
2. **搭建系统**：完成模块选型、接口连接、原理图或实验环境准备。
3. **调试验证**：通过串口、传感器、波形、测试表和现场现象定位问题。
4. **整理交付**：沉淀代码、报告、图片、证书和可复核的项目说明。

## 技术范围

- 硬件：STM32、OpenMV、OLED、传感器、电子秤模块、摄像头、PCB 和基础测量仪器
- 嵌入式：C / MicroPython、串口通信、I2C、传感器采集、电机控制和设备联调
- 视觉与数据：目标检测、单目视觉测量、SOM 聚类、CSV / Excel 数据整理和结果可视化
- 工程交付：原理图、流程图、测试记录、竞赛方案、项目报告、培训材料和证书归档
